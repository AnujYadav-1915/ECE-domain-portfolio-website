# ECE Domain Portfolio Website — Anuj Kumar

Clean, minimalist portfolio website built for an Electronics & Communication Engineering (ECE) graduate specializing in Formal Verification, Digital Design, and Embedded Systems.

## Tech Stack
- **Frontend**: React 18, TypeScript, Vanilla CSS
- **Bundler**: Vite
- **Deployment**: Vercel

## Featured Focus Areas
- **Formal Verification & Digital Design**: RISC-V 5-stage pipeline core, GPU Tensor Core MAC unit verifier, MESI L2 Cache Coherence protocol.
- **Embedded Systems**: ARM Cortex-M3 (STM32F103) UART-I2C Protocol Bridge using CMSIS drivers, DMA, and SPSC lock-free ring buffer.

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
